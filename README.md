# element-hider
This is a chromium extension used to block specific elements on specific websites.

## Update Log

- 1.0: It currently only blocks the in-game chat on Chess.com. Other things may come.

- 2.0: Now blocks every chat/message element on Chess.com. 

	- 2.1: Removed the textbox to customize awards and the message/chat icon on the left banner. Also added an interactive popup that asks if the user likes Porygon.

- 3.0: Combined the element-hider and proxy-closer extensions into one.

	- 3.1: Added a funny DK gif if the user likes Porygon.
	- 3.2: Blocked Google AI Overview on search results.
