# element-hider
This is a chromium extension used to block specific elements on specific websites.

## Update Log

- 1.0: It currently only blocks the in-game chat on Chess.com. Other things may come.

- 2.0: Now blocks every chat/message element on Chess.com. 

	- 2.1: Removed the textbox to customize awards and the message/chat icon on the left banner. Also added an interactive popup that asks if the user likes Porygon.

- 3.0: Combined the element-hider and proxy-closer extensions into one.

	- 3.1: Added a funny DK gif if the user likes Porygon.
	- 3.2: Blocked Google AI Overview on search results. 
	- 3.3: Blocked Chess.com profile bios and cards.

- 4.0: An attempt to stop this dumb version numbering. I should've thought more about this beforehand.
	- 4.0.1: Blocks the comments on instructables.com
	- 4.0.2: Fixed issue where instructuables.com comments weren't being hidden.
	- 4.0.3: Blocked message buttons on instructables.com
	- 4.0.4: Blocked every Google search variant URL that doesn't included a preset UDM code. This is to prevent students from clicking the "All" tab. Also added a feature that redirects search URLs that don't include a UDM code to UDM code 14 (Web) in case they started their search directly at www.google.com. Is this overkill? Maybe. We'll see if people complain.
